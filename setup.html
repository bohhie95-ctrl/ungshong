공유 후기 댓글 백엔드 만들기

아래 4단계만 하면 친구들이 로그인 없이 후기를 남길 수 있어요. 만든 뒤 나오는 웹 앱 주소만 채팅으로 보내 주세요.

1

script.google.com 열기

이미 Google에 로그인된 폰 브라우저에서 script.google.com 접속 → 오른쪽 아래 + 새 프로젝트.

2

기본 코드 지우고 붙여넣기

편집기에 있는 function myFunction() {} 를 모두 지우고, 위의 코드 전체 복사하기로 복사한 내용을 붙여넣은 뒤 저장(디스크 아이콘).

3

웹 앱으로 배포

오른쪽 위 배포 → 새 배포 → 유형(톱니)에서 웹 앱 선택 → 다음 사용자로 실행: 나, 액세스 권한: 모든 사용자 → 배포. 권한 화면이 나오면 본인 계정 선택 → 고급 → (프로젝트 이름)(으)로 이동(안전하지 않음) → 허용.

4

웹 앱 URL 보내기

나오는 https://script.google.com/macros/s/…/exec 주소를 그대로 복사해 채팅으로 보내 주세요. 나머지(시트 자동 생성·연결·테스트·배포)는 제가 합니다.

🛡️ 이 코드는 댓글 4칸(항목·닉네임·후기·시각)만 저장하고, 첫 실행 때 ‘웅숑 후기 댓글’ 시트를 자동으로 만듭니다. 이메일·전화번호 같은 개인정보는 저장하지 않아요.
